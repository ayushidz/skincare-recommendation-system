# SkinCare Match — Skincare Recommendation System

An explainable skincare recommendation system built with Python and Streamlit.

## What it does

SkinCare Match recommends products based on:

- Skin type
- Skin concerns
- Product category

It uses a **hybrid content-based recommendation approach** combining:

- TF-IDF
- Cosine similarity
- Skin-type matching
- Concern matching
- Category matching

The app also shows a match score, recommendation reasons, product images, and product links.
